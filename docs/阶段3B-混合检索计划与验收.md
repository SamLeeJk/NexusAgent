# 阶段 3B：混合检索计划与验收

## 目标与边界

本阶段解决词法检索无法稳定识别中英文同义改写的问题，同时保留阶段 3A 的不可变版本、显式发布、回滚、来源引用和无答案拒绝语义。实现范围只包含知识检索：不加入 SSE、人工接管、支付、外部模型调用或新的业务动作。

## 可验收成果

1. 在实现调参前冻结不少于 80 题的困难集，覆盖六个政策章节、中英文同义改写和困难负例，并在报告中保存数据集与语料 SHA256。
2. 同一接口支持 lexical、vector、hybrid 三种模式，报告三组 Hit@3、MRR@3、无答案拒绝率和延迟，不隐藏失败题。
3. Hybrid Hit@3 不低于 90%，MRR@3 不低于 80%，无答案拒绝率不低于 90%，且 Hit@3 比词法基线至少提高 10 个百分点。
4. 只索引 PostgreSQL 查询返回的当前发布分块；草稿不可见，发布与回滚后活动语料切换，重复同步不产生重复业务来源。
5. Qdrant 或向量模型不可用时自动走词法检索，不中断客服流程；响应和指标能够区分请求模式、实际模式与降级。
6. 默认测试不启动外部服务，不改变确认、事务、幂等或 checkpoint 语义；完成全量后端、PostgreSQL 专项、前端构建和容器验收。

## 实现

- `HybridRetriever` 在进程内延迟加载 FastEmbed，模型固定为 `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`，ONNX 仓库 revision 固定为 `faf4aa4225822f3bc6376869cb1164e8e3feedd0`，输出 384 维向量。普通词法模式不会导入模型运行时。
- 一个权威知识分块按中英文行和“章节标题 + 行”形成多个检索表示，结果再按 `chunk_id` 去重；引用仍返回数据库中的完整原文和行号。
- 原始问题与命中的退款、确认、重复提交、资金和取消等领域同义查询分别编码，按最高语义分数聚合；Hybrid 再用 RRF 合并词法与向量名次。
- 语义路径先检查受支持业务范围，余弦阈值为 0.35。超出已发布政策范围的问题返回 no-match，不让六个小语料分块强行回答所有问题。
- Qdrant 点使用确定性 UUID，payload 只保存块 ID、版本 ID、内容哈希和活动语料哈希。检索用活动语料哈希过滤，并再次与本次 PostgreSQL 活动分块白名单相交。
- Qdrant 服务器固定为 1.15.5，客户端固定为 1.15.1。服务位于 Compose `search` profile；模型缓存和向量存储分别使用命名卷。

## 冻结评测结果

数据集：`support-hybrid-v2`，48 个可回答问题、32 个无答案问题。数据集 SHA256：`7d3d142175f50faff7bea91f005830ce29305c4a518d50ef5d5cc49906e2db69`。

| 模式 | Hit@3 | MRR@3 | 无答案拒绝率 | 平均排序延迟 | P95 排序延迟 |
| --- | ---: | ---: | ---: | ---: | ---: |
| lexical | 0.0% | 0.0% | 100.0% | 0.06 ms | 0.09 ms |
| vector | 95.8% | 93.4% | 100.0% | 90.31 ms | 177.68 ms |
| hybrid | 95.8% | 93.4% | 100.0% | 136.78 ms | 192.58 ms |

四项预设门槛全部通过。延迟来自 Windows 本地进程和六个政策块的合成运行，排除数据库 I/O；每种模式计入首次延迟加载模型和索引，因此冷启动离群值可使平均值高于 P95，不能外推生产负载。词法集得分低是因为该困难集刻意使用原文外同义表达；阶段 3A 的直接词项回归仍需同时保留。逐题结果见 [JSON 报告](validation/stage3b-hybrid.json)。

## 启动与验收

```powershell
$env:NEXUS_HTTP_PORT='8001'
$env:NEXUS_RETRIEVAL_MODE='hybrid'
docker compose -p nexusagent-stage2 -f backend/docker-compose.yml --profile search up --build -d qdrant app
python backend/evaluate_hybrid.py --cache-dir backend/runtime/models
```

验收时依次检查：语义改写能引用正确章节；无答案问题返回 `found=false`；导入草稿后搜索不到草稿词；发布后可检索；回滚后恢复旧来源；停止 Qdrant 后同一请求返回 `mode_used=lexical` 与 `fallback=true`；恢复 Qdrant 后重新进入 hybrid；重复查询不重复写入业务来源。启用可观测性时检查 `nexus_retrieval_mode_total`。
