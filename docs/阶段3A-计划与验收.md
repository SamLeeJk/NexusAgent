# 阶段 3A：可维护知识库与检索基线

计划日期：2026-09-16。该阶段先建设可复现基线，向量/混合检索作为后续阶段，不将词法检索称作语义检索。

## 交付与验收条件

1. 管理员可从页面粘贴或导入 Markdown，预览分块并生成不可变版本；普通客户无法导入、发布或查看未发布草稿。
2. 发布显式切换活动版本；重复导入同一标题和内容不重复建版本；竞争发布使用预期版本校验，拒绝覆盖他人更新；可重新发布历史版本完成回滚。
3. 客户仅检索活动版本，结果包括标题、版本号、原文、行号与稳定引用；发布新版本后，旧会话中的引用仍能访问当时的内容，并标明已非当前版本。
4. 中英文词法检索使用同一接口；空查询和无足够匹配证据返回明确无结果。检索结果仅是资料，不能批准退款或改变订单规则。
5. 初始离线基准包含已标注相关章节的中英文可回答问题与无答案问题。提交固定用例、独立运行器、结果 JSON/Markdown；预设验收目标 Hit@3 ≥ 90%，MRR@3 ≥ 75%，无答案拒绝率 ≥ 87.5%。所有比率注明样本数，合成小样本不代表线上准确率。
6. PostgreSQL 迁移 002 保留现有用户、会话与申请；原业务测试持续通过；浏览器完成管理员导入发布、客户问答引用与版本更新演示。

## 实施顺序

- 增加管理员角色、知识文档/版本/分块表及消息来源字段，提供兼容旧数据库的迁移。
- 实现分块、不可变导入、并发安全发布和历史引用读取。
- 接入客服工作流，增加来源卡与管理页面。
- 运行固定基准、权限/迁移/恢复回归和端到端浏览器验收，更新部署实例与结果记录。

## 范围边界

文件仅按文本读取，不抓取外部 URL、不执行 Markdown 内容；演示资料只包含人工构造的售后规则。原有真实模型测试仍待明确授权，本阶段不发送资料到外部模型。语义相似度、向量数据库、重排、SSE 与完整人工工单不在本次完成声明中。

## 手动验收（当前实例）

访问 http://127.0.0.1:8001/，健康接口 `/api/health` 应显示 `mode=demo`、`storage=postgresql`。

1. 以 `admin / demo-admin-123` 登录，点击「知识库管理」。输入文档标识 `manual-guide`、标题和含正文的 Markdown；点击「保存草稿并预览」，确认分块及行号。也可直接选择 `.md` 文件。
2. 用独立浏览器会话以 `alice / demo-alice-123` 登录，此时该草稿不应出现在客户检索结果中，客户没有管理入口。
3. 管理员点击「发布此版本」和「确认发布」。客户新建会话，问「确认有效期政策」可验证内置政策；若测试自建文档，使用正文中的特有词加「政策」触发规则模式检索。
4. 点击回答下方来源卡，查看标题、版本、行号和原文。来源只作为资料，不改变退款执行资格或批准状态。
5. 相同文档标识导入不同正文，生成 v2 并发布。重新打开旧回答来源卡，应保留 v1 原文并标记历史版本；新检索使用 v2。
6. 对 v1 点击「回滚至此版本」并确认，客户新检索恢复为 v1。同样标题、内容再次导入不会重复生成版本。
7. 切回客服工作台，完成 O1002 资格咨询、显式申请和确认，验证原业务仍然可用。

## 可重复执行

标准 Python 3.12 环境安装 `backend/requirements.txt`，前端安装依赖后，在根目录执行：

```powershell
python -m pytest backend/tests -q
python backend/evaluate_knowledge.py
$env:NEXUS_TEST_DATABASE_URL='postgresql+psycopg://nexus:nexus_local@127.0.0.1:55432/nexus?connect_timeout=5'
python -m pytest backend/tests/test_support.py backend/tests/test_knowledge.py -q
Remove-Item Env:NEXUS_TEST_DATABASE_URL
$env:NEXUS_HTTP_PORT='8001'
docker compose -p nexusagent-stage2 -f backend/docker-compose.yml up --build -d app
$env:NEXUS_E2E_URL='http://127.0.0.1:8001'
npm --prefix frontend run build
npm --prefix frontend run test:e2e
```

评测运行器单独创建临时 SQLite 库，不修改演示库。JSON 记录用例/语料哈希、逐题结果、算法版本和门槛；耗时只包含排序，不能解释为接口延迟。浏览器截图位于 `frontend/test-results/`，属于忽略的本地产物。

本机原虚拟环境启动器失效，实际验证使用可用 Python 3.12 runtime 加载既有依赖；上述命令面向正常虚拟环境。真实模型测试尚未执行，合成评测也不是独立泛化测试。
